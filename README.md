# React 2048 Game

A fully functional 2048 game built with React and Vite.

## Features

- **Classic 2048 Gameplay**: Join the numbers and get to the 2048 tile!
- **Customizable Board Size**: Choose any board size from 2x2 to 10x10.
- **Advanced Merge Logic**: define your own merge expression using JavaScript (e.g., `A*B`, `A^B`).
- **Responsive Design**: Works on desktop (keyboard arrows) and mobile (touch swipes).

## Installation

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server
4. Run `npm run build` to build for production
